# 🐺 เกมล่าปริศนามนุษย์หมาป่า (Ultimate Werewolf Deluxe Edition)
### เว็บแอปภาษาไทยเต็มรูปแบบ สำหรับเล่นในครอบครัวผ่านมือถือ (iPhone, Android, iPad)

---

## ✨ จุดเด่นและฟังก์ชันเด่น

1. **เล่นผ่านมือถือได้ทันที ไม่ต้องโหลดแอป**:
   - เปิดผ่าน Safari บน iPhone/iPad หรือ Chrome บน Android ได้เลย
   - มี **QR Code** ขึ้นบนหน้าจอ แค่หยิบกล้องมือถือสแกนก็เข้าห้องเล่นได้ทันที พร้อมกรอกรหัสห้องให้อัตโนมัติ

2. **ระบบผู้ดำเนินเกมอัตโนมัติ (Web GM / Automated Moderator)**:
   - ไม่ต้องเสียสละ 1 คนมาเป็นคนเล่าเรื่อง ทุกคนในครอบครัวสามารถเป็นผู้เล่นได้พร้อมกัน
   - ระบบจะสั่งการแต่ละขั้นตอนในยามค่ำคืนและช่วงกลางวันให้อัตโนมัติ

3. **แอบดูการ์ดแบบเป็นความลับ (Hold to Reveal Gesture)**:
   - นั่งเบียดกันบนโซฟาก็ไม่ต้องกลัวคนข้างๆ แอบมอง! การ์ดจะคว่ำหน้าอยู่ ต้อง **แตะค้างไว้** เท่านั้นถึงจะเปิดดูบทบาท เมื่อปล่อยนิ้วการ์ดจะซ่อนตัวตนทันที

4. **รองรับบทบาทครบครันจาก Ultimate Werewolf Deluxe Edition**:
   - **ฝ่ายชาวบ้าน**: ชาวบ้าน, ผู้หยั่งรู้, บอดี้การ์ด, แม่มด, นายพราน, กามเทพ, ผู้ใหญ่บ้าน, เจ้าชาย, มนุษย์วานร, คนต้องสาป
   - **ฝ่ายมนุษย์หมาป่า**: มนุษย์หมาป่า, ลูกหมาป่า, สมุนหมาป่า, หมอผีสมุนหมาป่า
   - **ฝ่ายเป็นกลาง**: คนฟอกหนัง (ชนะคนเดียวถ้าโดนโหวตแขวนคอ), โดปเปลแกงเกอร์
   - ระบบคำนวณแต้มความสมดุลของการ์ด (Card Balance Rating) พร้อมปุ่มจัดสำรับการ์ดอัตโนมัติตามจำนวนผู้เล่น

5. **ระบบเสียงและดนตรีประกอบในตัว (Web Audio API)**:
   - มีเสียงหมาป่าหอนยามค่ำคืน, เสียงระฆังยามเช้า, เสียงส่องการ์ด, เสียงคลิกโหวต, เสียงระฆังมรณะ และเสียงฉลองชัยชนะ

## 🚀 วิธีเริ่มเปิดเกมให้คนในครอบครัวเล่น

### ขั้นตอนที่ 1: เปิดเซิร์ฟเวอร์
เปิด Terminal แล้วเข้าไปที่โฟลเดอร์โปรเจกต์ จากนั้นรันคำสั่ง:
```bash
npm start
```

### ขั้นตอนที่ 2: ให้คนในครอบครัวเข้าเล่น
เมื่อเซิร์ฟเวอร์เริ่มทำงาน จะแสดง URL บนหน้าจอ:
- **บนคอมพิวเตอร์ / iPad เครื่องที่เปิด**: เปิดเบราว์เซอร์ไปที่ `http://localhost:3000`
- **บนมือถือ iPhone / Android ของคนในบ้าน (Wi-Fi เดียวกัน)**: 
  - สแกน QR Code จากหน้าจอหัวหน้าห้อง หรือเปิด URL เช่น `http://192.168.1.XXX:3000`

## 📱 โครงสร้างโปรเจกต์
- `server/index.js` - เซิร์ฟเวอร์ Node.js + Express + Socket.io + QR Code generator
- `server/gameRoom.js` - Game Engine และกฎกติกาการเล่นทั้งหมด
- `src/data/roles.js` - ข้อมูลบทบาทและการแปลภาษาไทยของ Ultimate Werewolf Deluxe
- `src/components/` - หน้าจออินเทอร์เฟซภาษาไทย (Lobby, RoleReveal, NightView, DayDiscussion, VotingView, GameOver)
- `src/utils/audio.js` - ระบบสังเคราะห์เสียงเอฟเฟกต์บรรยากาศในเกม
